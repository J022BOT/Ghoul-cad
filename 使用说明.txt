一、怎么用（最重要的一条）
------------------------------------------------------------------------
  双击本文件夹里的「启动 Ghoo.bat」即可。

  它会自动完成：
    1) 用本文件夹内的 Python 启动 Ollama 本地模型服务（无需安装）
    2) 放出桌宠 Ghoo（桌面右下角）
    3) 启动网页版 CAD 工作台，并自动打开浏览器  http://127.0.0.1:8765

  ★ 第一次启动需要 1~3 分钟（模型加载），窗口里会有进度提示，请耐心等。
  ★ 那个黑色窗口就是「网页服务本体」，用的时候别关；关掉窗口＝停止网页服务。
    （桌宠是独立进程，关窗口后仍会留在桌面上，右键它 → 退出… 才能关。）

  ★ 想一次性全部关掉（模型服务 + 网页 + 桌宠）并直接弹出 U 盘：双击「关闭运行.bat」。
    它会依次做五件事：
      1) 结束本文件夹里的 python / ollama 进程（不会动电脑上其他程序）
      2) 关掉启动器残留的黑窗口
      3) 关掉停在本盘上的资源管理器窗口
      4) 刷新写入缓存
      5) 弹出 U 盘：先用系统级「释放卷 + 弹出介质」，被拒绝再走资源管理器的弹出
    弹出成功后盘符会消失，直接拔盘即可。
    ★ 重要：这个脚本只会「释放卷」，绝不会删除盘符，重新插入必定还是原来的盘符。
      （旧版本用的 diskpart remove all 会连盘符一起删掉，插上就再也看不到 U 盘，已彻底移除。）
    只想关闭不想弹出：脚本倒数第 8 秒内按 N。

  ★ 万一 U 盘插上后毫无反应（资源管理器里没图标、托盘里没有「弹出」选项）：
    双击桌面上或 D 盘根目录的「修复U盘盘符.bat」，按提示点「是」给管理员权限。
    它只做一件事：给「没有盘符的移动磁盘」补一个盘符，不格式化、不删数据、不写任何文件。
    注意必须从电脑本地磁盘启动它 —— U 盘没盘符时是读不出任何内容的。

  想创建桌面快捷方式：双击「创建桌面快捷方式.bat」。
  只想放桌宠、不要网页：双击「只启动桌宠.bat」。
  运行不正常时：双击「诊断环境.bat」，它会打印自检结果，方便排查。


二、目录结构
------------------------------------------------------------------------
  python\              便携 Python 3.13 运行时（含 numpy/Pillow/opencv 等全部依赖）
  app\                 程序本体（桌宠 desktop_pet.py、网页 web_app.py、CAD 内核等）
  ollama\ollama.exe    Ollama 引擎（本地大模型服务）
  ollama\models\       两个模型：
                         qwen2.5-coder:7b  —— 对话 / 画图指令（约 4.7 GB）
                         qwen2.5vl:7b      —— 网页「吃图识别」看图（约 5.9 GB）
  LibreCAD\            LibreCAD 便携版（导出 DXF 后自动打开看图）
  tools\libredwg\      DXF → DWG 转换器（LibreDWG，离线、免安装，出 R2000）
  tools\homotope\      线稿矢量化引擎 Homotope（网页识图辅助，纯本地不上传图片）
  tools\node\          Node 22 运行时（只给 Homotope 用，包内自带，无需另装）
  CAD\                 画出来的 DXF / DWG 文件都存这里
  启动 Ghoo.bat        一键启动（推荐）
  关闭运行.bat         一键全部关闭并弹出 U 盘（模型服务 + 网页 + 桌宠）
  eject_native.ps1     关闭脚本调用的「保盘符弹出」内核（别删）
  修复U盘盘符.bat      急救工具：U 盘丢失盘符时补回来（桌面上另有一份）
  repair_letter.ps1    修复工具的源码（可读，便于核对，平时用不到）
  只启动桌宠.bat       只放桌宠
  诊断环境.bat         环境自检
  创建桌面快捷方式.bat  在桌面放一个快捷方式


三、换电脑 / 换 U 盘会不会失效？
------------------------------------------------------------------------
  不会。所有路径都写成「相对本文件夹」，盘符变成 F:、G: 都照样能用。
  整个文件夹可以随意改名、移动、拷到别的电脑，不需要重新安装任何东西。

  前提只有两条：
    · 目标电脑是 64 位 Windows 10 / 11；
    · 存储介质是 NTFS 或 exFAT（FAT32 单文件上限 4 GB，装不下模型文件）。

五、常见问题
------------------------------------------------------------------------
  1) 双击没反应 / 窗口闪一下就没了
     → 双击「诊断环境.bat」看缺什么；多半是文件夹没拷全。

  2) 提示 11434 端口被占用
     → 电脑上已有别的 Ollama 在跑。本程序会自动接管（会先结束旧进程），
       若你不想这样，请先手动退出其他 Ollama 程序再启动。

  3) 提示 8765 端口被占用
     → 已经有一个本程序在运行了，直接开浏览器访问 http://127.0.0.1:8765 即可。

  4) 桌宠不见了
     → 它可能被拖到屏幕边缘或最小化了；双击「只启动桌宠.bat」可再放一只。

  5) 杀毒软件报警
     → 便携 Python + 本地大模型会读写大量文件，属正常行为，请放行本文件夹。

  6) U 盘运行很慢
     → 模型有 10 GB，USB 2.0 接口加载会很慢。建议用 USB 3.0 及以上接口。
       追求速度的话，把整个文件夹拷到电脑硬盘上再运行。

  7) 图纸里的文字在 LibreCAD 里变成一个个小方框
     → 这是 LibreCAD 的「草稿模式」被打开了（它为了省性能会把所有文字画成
       空心方框）。从网页里打开图纸时程序会自动关掉它；若你是手动双击打开的，
       请点菜单 视图(V) → 草稿模式 把勾去掉，窗口标题栏里的「[草稿模式]」
       消失即生效。已经在运行的 LibreCAD 需要重启一次。

  8) 网页识图里的「Homotope 辅助」是什么？
     → 一个额外的线稿矢量化引擎，纯本地运行、不上传任何图片。
       默认「自动」：先用 OpenCV 提线，识别不出东西或结果太碎时才让它接手；
       「只用」＝只走它；「关闭」＝完全不用。它靠 tools\node\node.exe 启动，
       若下拉框被禁用并显示原因，就是该文件缺失（诊断脚本会检查）。

  9) 导出 DWG 时弹「dxf2dwg.exe - 系统错误 找不到 libiconv-2.dll」
     → tools\libredwg\ 目录里少了依赖文件。dxf2dwg.exe 本身只依赖
       libredwg-0.dll，但后者还依赖 libiconv-2.dll；缺了它 Windows 会弹这个
       框并把转换卡死。把上面两个 DLL 都放回 tools\libredwg\（与 dxf2dwg.exe
       同目录）即可。「诊断环境.bat」会逐项检查这些文件。

 10) 弹「未安装 ezdxf，无法解析 DXF」/ 提示缺 numpy、cv2（图片识别不可用）
     → 说明启动用的不是本包自带的 Python（numpy / cv2 / ezdxf 只装在包内
       python\python.exe 里，用系统里那个"干净"的 Python 启动就会缺）。
       现在的版本会自动纠正，而且找得很宽：
         1) 先看本文件夹的 python\python.exe；
         2) 再看各个盘根目录下的 ...\J022-Ghoul-Portable\python\python.exe
            —— 所以就算从别的位置（比如开发目录）启动，也能找回本包解释器；
         3) 最后扫 PATH 和常见安装目录里的 Python，逐个试能不能 import。
       找到就自动重启自己，日志里会出现这一行：
         [环境] 自动切换到可用解释器并重启：D:\...\python\python.exe
       网页顶部还会出现一条红色横幅，直接写明当前用的解释器和解决办法。
       万一真的没有可用 Python：装一下依赖（pip install numpy opencv-python），
       或指定环境变量：
         set J022_PYTHON=D:\J022-Ghoul-Portable\python\python.exe
       「导入 DXF」已不依赖 ezdxf（内置纯 Python 解析器，二进制 DXF 除外）。
       想确认到底是谁在跑：浏览器访问 http://127.0.0.1:8765/api/env 。


六、体积与卸载
------------------------------------------------------------------------
  总体积约 11.7 GB（其中模型 10 GB）。占用空间可以随时查看。

  卸载＝直接删除本文件夹。
  注意：它不会往系统里写任何东西、不装服务、不改注册表，
       唯一的外部痕迹是浏览器访问记录与桌面快捷方式（可手动删）。


七、想改模型 / 路径（进阶）
------------------------------------------------------------------------
  设置以下环境变量即可覆盖默认值（一般用不到）：
    OLLAMA_MODELS      模型库位置
    OLLAMA_HOST        Ollama 服务地址（默认 http://localhost:11434）
    PET_MODEL          桌宠对话模型名（默认 qwen2.5-coder:7b）
    J022_CAD_DIR       DXF 输出目录
    J022_LIBRECAD      LibreCAD 路径
    J022_OLLAMA_EXE    ollama.exe 路径
    J022_PYTHON        指定启动用的 python.exe（跳过自动查找）
